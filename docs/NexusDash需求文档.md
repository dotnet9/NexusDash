# NexusDash 功能清单

## 定位

面向开发者、运维人员和高级用户的跨平台系统资源管理工具。主流程是发现异常进程、查看资源占用、定位网络通信、执行安全处置。

## 已有功能

- 系统概览：CPU、内存、磁盘、网络实时指标与趋势。
- 进程树：PID、父 PID、名称、发布者、CPU、内存、磁盘、TCP/UDP、GPU 列。
- 搜索：按 PID、进程名、路径、命令行过滤。
- 进程详情：启动时间、路径、命令行、权限受限提示。
- 网络连接：选中进程后展示 TCP/UDP、本地端点、远端端点、状态、最后采样时间。
- 进程处置：结束进程、结束进程树、关联进程确认弹窗。
- 热点视图：Treemap 展示内存占用较高进程。
- 设置：深色/浅色主题、zh-CN、zh-Hant、en-US、ja-JP。
- 持久化：主题、语言、窗口尺寸、进程列可见性。

## 近期功能

- 进程列表排序：PID、CPU、内存、磁盘、网络。
- 列宽持久化：重启后恢复用户列宽。
- 网络连接右键操作：复制端点、复制整行连接信息。
- 快照导出：进程列表、网络连接、选中进程详情导出 JSON/CSV。
- 过滤器：有网络连接、高 CPU、用户进程、隐藏系统进程。
- 选中进程时间线：最近 60 秒 CPU、内存、磁盘、网络趋势。

## 后续功能

- 句柄与文件：Windows 句柄、Linux/macOS fd/lsof。
- 模块视图：DLL、so、dylib、版本、路径、签名状态。
- 线程视图：线程 ID、CPU、状态、启动地址或描述。
- 服务与启动项：Windows SCM、Linux systemd、macOS launchd。
- 管理员/root 重新启动入口。
- 高风险网络操作：评估 Windows TCP 连接断开能力。

## 体验要求

- 首屏以进程表为核心，右侧展示选中进程上下文。
- 表格行高 30-34px，文本不遮挡，长文本截断或滚动。
- 深色/浅色主题下主表、页签、弹窗、状态栏文字必须可读。
- 高风险操作统一走确认弹窗，并展示失败原因。
- 空状态区分无数据、权限不足、平台暂不支持。

## 验收要点

- 应用启动后 3 秒内出现进程列表或明确错误。
- 选择任一进程后右侧详情更新。
- 有连接的进程能在网络页展示连接明细。
- 刷新时保留展开、滚动、选中状态。
- 切换主题和语言后主流程无明显未翻译或弱对比文字。
