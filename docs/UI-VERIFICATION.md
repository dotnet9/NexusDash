# 界面与 NativeAOT 复核

2026-10-15，版本 0.1.10。主要修正主题模式与配色混用、设置页切语后仍保留旧文本，以及派生窗口没有应用尺寸和字体样式的问题；关于页改用 Toolkit 更新服务。

## 已验证

- CodeWF.Avalonia 12.1.4.18 与 Toolkit 1.0.0.18 通过 NuGet 引用；宿主 JSON 输出到程序目录，强类型键由 T4 生成。
- 两个目标框架 Release 构建成功；仓库 `scripts/publish.ps1 -RuntimeIdentifier win-x64` 完成 Windows NativeAOT 发布。
- UI 验证器另行 NativeAOT 发布并实际运行，98 项断言通过，24 张原生 PNG。覆盖真实窗口 1440 × 760、40 px 标题栏和字体回退，三态八色的独立保存、旧配色迁移、四语设置与关于页、真实版本和编译时间。
- 在已打开的设置页上切语，校验属性变更通知及当前下拉选项文本，避免只检查资源查询值。系统模式与配色分别保持。
- 更新检查、失败、缺少校验文件降级、下载、校验失败、手动安装、重复检查、动态切语、取消及关闭期间取消使用受控服务测试，不启动真实安装器。
- 原型门禁检查四个导航入口、四语 × 三态 × 八色共 96 组组合、系统变化及更新 / 取消状态，无脚本异常。

## 边界

`design/index.html` 保留旧概念稿，`design/studio.html` 补齐现有产品导航和本轮确认的设置流程。原始三卡片概念稿与当前四监控卡布局存在版本差异，不能宣称完全像素一致。实际截图采用真实系统只读采样；没有测试结束进程等破坏性操作。

锁屏期间使用离屏渲染与无头浏览器；真实鼠标、输入法、多 DPI、多显示器、真实安装器和其他操作系统未完成验收。原生发布仍有第三方裁剪 / AOT 分析警告，通过的路径不代表所有反射分支均被覆盖。
