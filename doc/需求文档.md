# NexusD 开发提示词

## 项目概述
**应用名称**：NexusD（暂定）  
**项目类型**：科幻风格系统监控仪表盘（Avalonia + C# 桌面应用）  
**核心概念**：将系统性能数据（CPU/内存/磁盘/网络）可视化为一艘星际飞船的仪表盘，采用程序员友好的代码编辑器主题，融入科幻音效和交互反馈。

---

## 核心功能模块

### 1. 数据采集层
```
- 跨平台性能计数器
  - CPU使用率（总体/核心）
  - 内存占用（已用/可用/交换）
  - 磁盘I/O（读写速度/使用率）
  - 网络流量（上行/下行/连接数）
  - 温度传感器（可选，依赖硬件支持）
- 更新频率：1秒
- 历史数据：保留最近60秒用于趋势显示
```

### 2. 视觉设计规范
```
- 主题：VS Code Dark Plus 变体
  - 背景色：#1e1e1e
  - 主色调：幽蓝（#007acc）
  - 高亮色：青色（#4ec9b0）
  - 警告色：琥珀色（#d7ba7d）
  - 危险色：赤红（#f14c4c）

- 科幻元素：
  - 全息投影效果（半透明、发光边缘）
  - 网格背景（极坐标/直角坐标可选）
  - 扫描线动画（缓慢移动的横线）
  - 状态指示器：圆形/扇形/柱状混合
```

### 3. 仪表盘组件
```
A. 核心状态面板（飞船“反应堆”）
   - CPU：旋转的能量核心动画，转速随使用率变化
   - 内存：分段式填充条，类似“护盾容量”
   - 温度：色温条（蓝→黄→红）

B. 存储阵列（磁盘）
   - 多个“存储舱”方块，填充比例表示使用率
   - I/O速度：动态流动粒子效果

C. 通信阵列（网络）
   - 上传/下载：双向光流动画
   - 连接点：闪烁的节点网络图

D. 系统日志（飞船“黑匣子”）
   - 滚动显示关键事件
   - 可切换：原始数据/叙事化描述
   - 示例：“反应堆核心负载增加至75% - 建议检查散热系统”
```

### 4. 交互与反馈
```
- 预警系统：
  - CPU > 90% 持续5秒 → 闪烁红框 + 警报音效
  - 内存 > 95% → 护盾破碎动画效果
  - 磁盘空间 < 10% → 存储舱红色警报

- 音效库：
  - 背景：飞船引擎低鸣（可调节音量）
  - 正常：轻微电子嗡鸣
  - 警告：星际迷航“红色警报”（可配置经典/现代版）
  - 点击：触控面板音效

- 快捷键：
  - F11：全屏仪表盘模式
  - Ctrl+数字：切换预设布局
  - Space：暂停/恢复数据更新
```

## 技术实现要点

### 架构设计
```
UI层 (Avalonia)
  ├── 自定义控件（仪表、量表、粒子动画），基础控件使用AtomUI，使用.NET 10框架
  ├── 数据绑定（ReactiveUI/CommunityToolkit.Mvvm）
  └── 主题管理器（明/暗/自定义）

业务层
  ├── 性能采集服务（跨平台封装）
  ├── 数据规范化（0-100% 映射到动画参数）
  └── 预警规则引擎

基础设施
  ├── 音效播放（NAudio + 资源文件）
  ├── 配置持久化（JSON）
  └── 日志记录
```
### 3D元素（可选进阶）
```
- 使用Avalonia 3D控件或集成HelixToolkit
- 飞船简化模型：旋转的能量核心
- 数据流可视化：3D粒子轨迹
- 注意：保持60fps性能，可关闭3D模式
```
