# NexusDash Changelog

## 2026-05-21

- Added real-time process tree monitoring with Apps, Background processes, and Windows processes groups.
- Added process icon display, using the executable icon for application processes when available.
- Added process search by name, publisher, or PID, with grouped flat search results.
- Added a per-process TCP/UDP communication panel for connection counts and endpoint details.
- Added right-click confirmation flows for ending a process or a process tree.
- Added dark/light theme switching and multi-language switching.
- Added a settings center for appearance, changelog, and about information.
- Added a process table column visibility menu with persisted non-critical column choices.
