# NexusDash 产品交互原型

`index.html` 是可复制到空目录使用的单文件离线原型。主窗口默认带桌面留白、外边框、标题栏和三个窗口按钮；内容以当前 AXAML 功能重整，早期概念稿仅保留在 `scripts/prototype/legacy.html` 的历史源码中。

| 产品区域 | 原型功能 |
| --- | --- |
| 主窗口 | 40 px 标题栏、搜索、220 px 导航、5 px 左右分隔器、独立日志分隔器、88 px 日志、42 px 状态栏 |
| 进程管理 | 2 × 2 指标与曲线、进程树样例、选择详情、Treemap、结束前确认、暂停恢复、样例快照导出 |
| 文件搜索 | 名称和目录输入、搜索／取消、六列表格结果 |
| 硬件信息 | 分组信息表、刷新状态 |
| 外观 | 独立三态主题、八色下拉、四语 2 × 2 单选项、118 px 标签列的窗口尺寸偏好、设置保存与恢复 |
| 关于 | 产品图标、七项元数据、检查／发现／下载／安装交接／取消／失败／无资产状态 |

宿主四语资源由 `scripts/sync_design_resources.ps1` 同步；原型运行不访问进程、真实文件、网络和安装器。句柄、服务与启动项沿用产品的能力说明，不把原型样例标为已完成的系统后端。关于中的编译时间固定为 `2026-10-15 00:00:00`，生产程序继续显示真实元数据。

```powershell
pwsh scripts/sync_design_resources.ps1 -Check
npm ci --prefix design/tests
npm test --prefix design/tests
```

修改源码后运行 `pwsh scripts/build_standalone_prototype.ps1`。审计复制唯一 HTML 到空目录并阻断所有外部资源，覆盖四语言 × 三态 × 八色、系统明暗变化、偏好恢复、进程／搜索／硬件交互和更新状态；要求无脚本异常。

## 对照基线与可见差异

主窗口按 1440 × 760 原生截图对照，设置内容按 1080 × 680 对照，分别用 `?capture=window` 和 `?capture=settings` 去掉展示留白。43 个明确量测的矩形区域最小交并比为 99.80%，覆盖主窗口外壳、指标卡、日志、状态栏及四语设置／关于区域；这是区域几何对照，不是整页像素还原率。

已对齐 2 × 2 语言单选排列、主题下拉左对齐、表单列宽、关于图标和更新区位置。浏览器与 Semi 原生控件的圆点、边框、字体抗锯齿和图标笔触仍有差异；曲线、数据量、日志与编译平台是样例。原生采样、权限提升、真实结束进程、文件管理器和系统安装仍需在应用与目标系统验收，原型不替代这些验证。
